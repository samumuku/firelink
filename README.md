# firelink
Personal project for sharing files and other utilities via Peer to Peer and Chunking.
Used by me and my friends

# Versions

- Python : **`3.14.2`**

# Developer mode

### Installing the dependencies

In the **`src`** folder
```bash
pip install -r requirements
```

### Launch the app

In the **`src`** folder
```bash
python main.py
```
